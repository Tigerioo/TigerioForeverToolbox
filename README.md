# Tigerio’s Forever Toolbox

**Tigerio 的无限升级工具箱**：面向《魔兽世界：无限》的独立升级辅助插件，优先记录冒险旅程，并逐步探索与现有插件配合。项目与 TigerUI 独立，安装本插件不需要卸载 TigerUI。

## 升级日历

- 记录启用插件后各角色的升级日期，以及每个角色每天的在线时长。
- 日历顶部显示当前角色的游戏总时长和本级时长，数据来自客户端的游戏时长查询；登录或升级后的查询可能在聊天栏显示游戏自带的时长消息。游戏未返回数据时显示“未知”。
- 获得可靠的本级时长快照后，升级时会结合本次在线经过时间估算该级耗时，并在升级记录后显示“约”。没有快照的历史升级无法补算，离线日期差不会作为在线耗时。
- 日历右侧按时间显示升级记录；仍会记录在线时长，但不在日历中显示。徒步时间采样已停止，既有数据保留。
- 账号级本地数据用于在同一客户端账号下查看已登录过的角色；时长包含挂机，按电脑本地日期分日。
- 如果当前角色启用了冒险手记（AdventureJournal），登录时导入该角色已加载的升级记录；迟加载时也会尝试导入。相同等级、时间相差不超过 5 秒的记录视为同一次升级，导入记录会标明来源。
- 冒险手记的数据按角色保存：其他角色须各自登录并启用这两个插件后才能导入。不能恢复冒险手记中没有的升级日期，也无法凭空恢复此前每天的在线时长；导入不会修改冒险手记数据。
- 游戏插件数据通常在正常退出或 `/reload` 时保存。崩溃、强退或掉线可能导致最近尚未落盘的数据丢失；换电脑或账号需要自行迁移游戏保存数据。

## 安装与使用

将 `TigerioForeverToolbox` 文件夹放入无限服客户端的 `Interface/AddOns`。登录每个想记录的角色并启用插件，然后输入 `/tft` 打开日历。首次使用及客户端 API 行为仍需在无限服实测。

## 同行记录

输入 `/tftparty`，或点击工具箱右侧的同行记录图标，查看启用功能后遇到的五人小队队友。记录包括姓名、职业、组队期间自己所在地点、当时观察到的等级和最近能确认的当前等级；等级或地点在稍后才可读取时会标明记录时间。团队、战场和竞技场不记录。记录保存在本地账号插件数据中，同一账号的角色共享；功能启用之前的队友无法补录。

当前状态和等级仅依据当前队伍或角色唯一标识匹配的游戏好友列表；无法确认时显示“未知”，不把旧等级当作当前等级。功能不会自动查询 `/who`、添加好友或发送消息。客户端可能限制访问部分数据，实际效果需游戏内验证。

## 战斗 HUD

输入 `/tfthud`，或点击工具箱右侧的战斗 HUD 图标，打开设置页并启用 HUD。HUD 默认关闭，设置和位置按角色保存。左侧和右侧各有四个技能槽，下方有六个；点击设置页的槽位可搜索并选择当前角色已学的主动技能，也可从技能书拖入，右键清空。未配置的技能槽在游戏 HUD 上隐藏，设置页仍可查看。技能使用所选的具体等级。HUD 上的技能槽设计为点击施放，并通过客户端冷却控件显示冷却。

设置页的“移动位置”用于解锁并拖动 HUD，完成后点击“锁定位置”。技能配置、启停和移动需要在脱战后操作。玩家与目标血条以及资源百分比受客户端数据限制；无法读取时显示“—”。中间一个资源球按当前职业和形态显示主资源，如法力、能量或怒气，并使用客户端提供的资源配色；颜色不可读取时以中性白色显示。不修改 TigerUI、游戏动作条或原有快捷键。技能施放、拖动、受限场景及界面效果尚需在无限客户端实测。

启用 HUD 时会尝试隐藏暴雪原生玩家和目标框，关闭 HUD 后恢复其原父框，不主动改变它们自身的显示状态。血条内显示玩家和目标的名称；HUD 提供双方施法／引导进度，以及目标等级、职业、关系与可确认的状态。可读取时显示少量增益和减益图标，不保证完整光环、持续时间或目标的目标。客户端信息受限时不猜测。必要的目标或施法接口不可用时保留原生头像框；其他插件接管或客户端限制时，系统框也可能无法隐藏，设置页会提示。若系统施法条没有附着于玩家头像，它可能与 HUD 施法条同时出现。实际显示及战斗兼容性需游戏内确认。

## 全局界面

工具箱右侧“全局界面”或 `/tftui` 可分别控制小地图、聊天框和小队与团队样式，设置按角色保存、默认开启，需脱战调整。小地图使用铜色圆环替换原生边框，保留地图功能、追踪、缩放、邮件提示和地图图钉；低频活动按钮和 LibDBIcon 插件按钮在鼠标移至小地图时显示。关闭小地图样式可恢复按钮和原边框。聊天样式为聊天窗口、输入框和标签添加深色底和细边，不改聊天记录、输入、频道、字体或位置。小队与团队样式在原生普通小队及紧凑小队和团队成员生命条上添加铜色细边，保留原生头像、颜色、布局及交互；战斗中出现的新框体在脱战后处理。显示层级、其他插件兼容及实际效果尚需游戏内确认。

## 五人副本任务查询

输入 `/tft dungeon`，或点击工具箱右侧的副本图标，搜索并选择副本查看任务线索。少量攻略由本项目独立整理，其余条目可复制所列参考资料网址。游戏接口可用时会显示当前角色的已交付或进行中状态；未知不代表未接取或不可接。

实际加载兼容契约 4 的 QuestieDB 时，工具箱会只读查询本地数据库、按副本区域列出候选任务和前置链，并尝试显示接取来源及任务状态；首次查询会分批建立索引。未加载或接口不可用时仍可查看独立整理的资料。Questie 和白云飞中文补丁实际启用时按其自身规则提供修正与翻译，不能因为目录存在就假定它们已启用。

按归属区域查找可能遗漏跨区、职业任务或新副本，也可能包含不适用于当前角色的候选项；有些新副本尚无可核实的区域编号。资料并非完整任务清单，也不是进入副本所必需的开门条件。接取条件和客户端界面均需游戏内核实；条目的资料链接可供进一步查询。本项目不复制或打包 QuestieDB 数据。

## 武器大师查询

输入 `/tft weapon`，或点击工具箱右侧的武器图标，可按武器类别查看对应大师的城市和位置；默认显示当前阵营，可切换到双方，也可以查看全部已收录的大师。魔杖等不由武器大师教授的情况会单独说明。

现收录六座传统主城的八位大师作为出行参考，可能遗漏无限服新增地点；坐标为旧资料约数，教授项目和位置尚未在游戏内逐项验证，存在争议的项目会标明。职业、等级及已学技能等会影响能否训练，最终以游戏内训练界面为准。参考：[Forever 武器技能攻略](https://howtovideogame.com/wow-forever-weapon-skills-train-where/)、[训练师资料与不确定项](https://wowforeverguides.com/tools/weapon-trainers)。

## 奇珍图鉴小游戏

输入 `/tft luck`，或点击工具箱右侧的图鉴图标。这是账号共享、保存在本地的**虚拟收藏**：游戏内著名物品只是图鉴主题，不会发放真实装备、坐骑或其他游戏物品，也不消耗金币、购买点数或发送消息。

- 已识别的本人或当前宠物最后一击有 25% 几率获得碎片；触发时获得 1 或 2 枚，二者等概率。攒够 20 枚后可主动抽一次，不会自动抽。
- 每次基础概率：普通 70%、精良 25%、史诗 4%、传说 1%。这些是小游戏档位，与游戏内物品实际品质或真实掉率无关。同档内等概率，重复收藏会累计次数。
- 连续 10 次未获得史诗或传说，第 11 次至少获得史诗；连续 50 次未获得传说，第 51 次必得传说。两种保底同时触发时，传说保底优先；史诗保底中史诗与传说按 4:1 抽取。
- 击杀识别使用客户端独立 `PARTY_KILL` 事件，只计身份可读取且最后一击属于玩家或当前宠物的 `Creature`；队友最后一击不计，召唤物、宠物及副本覆盖须实机验证。客户端限制信息时无法补算，`Creature` 也可能包含非敌对生物；会话内按目标去重。
- 碎片、图鉴和保底是本地账号级插件数据，不涉及真实掉落或官方成就，也不用于可信排行榜。退出或 `/reload` 时按游戏保存机制写入，历史击杀无法恢复。
- 图鉴采用少量手工整理的物品名称和编号，图标由游戏客户端提供；例如参考 [雷霆之怒](https://www.wowhead.com/forever/cn/item=19019) 和 [死亡军马的缰绳](https://www.wowhead.com/forever/cn/item=13335)。图鉴收录不代表当前服务器中一定能获得这些真实物品。

## 移动框体

输入 `/tft move` 开启移动模式，将鼠标移到目标窗口，再拖动窗口上方出现的手柄；再次输入同一命令退出。位置按角色保存在本插件中。输入 `/tft resetmove` 可清除当前角色由本插件保存的位置，随后输入 `/reload` 重新加载界面；游戏或其他插件自行保存的布局可能仍然生效。

支持用户选择的、可见且具名的顶层游戏或插件窗口。受保护或禁止访问的框体、无名称的框体和战斗中无法移动；由游戏或其他插件持续管理的布局也可能覆盖位置。移动手柄和实际兼容范围尚需在无限服实测。

## 系统动作条

普通系统动作条使用 HUD 铜色边框，默认透明，鼠标移入对应动作条时显示；编辑模式中显示，技能和快捷键仍由系统管理。在工具箱的“HUD 设置 → 系统动作条”中可分别控制样式、默认隐藏和鼠标悬停显示；隐藏关闭时悬停设置暂不生效。载具、宠物、姿态和额外动作按钮保持原有行为。仍可使用 `/tftbars off` 和 `/tftbars on` 切换样式；设置按角色保存。

透明动作条仍可接收鼠标，可能影响其下方界面的点击；若已有插件修改了动作条透明度，本插件不会接管该透明度。实际悬停、战斗中显示和边框效果需游戏内验证。

## 升级辅助与兼容

- **装备提醒**：发现背包中可比较的更高装等装备时，屏幕会闪烁提示；悬停查看物品，使用“上件／下件”浏览候选。可确定安全目标的单槽护甲支持左键装备；戒指、饰品和武器提示需手动更换。仅比较现有装备与条件明确的同部位物品，空槽、唯一装备和复杂武器组合可能不提示。装等不等于实际提升，请核对属性和效果。
- **装备操作限制**：战斗中隐藏提醒并在脱战后重新检查；背包或装备变化时旧提示失效。商人、银行等交互打开、存在同名或同编号物品、物品资料尚不完整或客户端无法确认安全装备时，请手动更换。实际客户端按钮行为尚需实机验证。
- **任务怪**：客户端能确认敌对 NPC 与当前任务相关时，在可访问的姓名板上显示“任务”；切换到该目标时还有一次聊天提示。接口不可用或目标受限制时不显示，姓名板必须在游戏中开启。
- **服务 NPC**：根据客户端提供的少量明确服务称谓，在友方 NPC 姓名板侧边显示标签；选中目标时改在目标框附近显示，避免重复。只识别精确的旅店、银行、飞行、拍卖、兽栏、商人、训练师和修理等通用称谓；无法确认时不显示。战斗中姓名板标签可能暂时隐藏，脱战后刷新。
- **与 TigerUI 并存**：装备界面提醒保持可用，本插件不再输出装备聊天提醒；TigerUI 的装备聊天提醒由其自身设置控制。实际加载 TigerUI 且对应的任务怪高亮或服务图标开启时，本插件暂停相应提示。不会修改 TigerUI 设置。
- **Questie / QuestieDB 和中文补丁**：各自管理任务数据与翻译；本插件不复制、覆盖或修改它们。任务怪的目标切换提示与 Questie 的鼠标提示可能同时出现。
- **PocketZoneMap**：可与日历并用；随行地图不会因此自动显示 Questie 图钉。本插件未接入没有稳定公开接口的第三方地图图层。

任务发布 NPC 提示暂未集成：Questie 的候选 NPC 数据依赖内部接口，尚无经验证的稳定公开接口，直接接入可能造成重复提示或版本兼容问题。宏工坊和声望工具仍是后续可选项。

Questie 相关历史贡献授权存在复杂性，本项目不包含其代码或数据库。上述客户端接口及界面效果仍需在无限服实测，插件目录存在不代表角色已启用插件。
