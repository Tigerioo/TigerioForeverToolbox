# Tigerio’s Forever Toolbox

**Tigerio 的无限升级工具箱**：面向《魔兽世界：无限》的独立升级辅助插件，优先记录冒险旅程，并逐步探索与现有插件配合。项目与 TigerUI 独立，安装本插件不需要卸载 TigerUI。

## 升级日历

- 记录启用插件后各角色的升级日期，以及每个角色每天的在线时长。
- 账号级本地数据用于在同一客户端账号下查看已登录过的角色；时长包含挂机，按电脑本地日期分日。
- 历史升级日期和启用前的在线时长无法凭空恢复；已有冒险手记数据的导入尚未实现。
- 游戏插件数据通常在正常退出或 `/reload` 时保存。崩溃、强退或掉线可能导致最近尚未落盘的数据丢失；换电脑或账号需要自行迁移游戏保存数据。

## 安装与使用

将 `TigerioForeverToolbox` 文件夹放入无限服客户端的 `Interface/AddOns`。登录每个想记录的角色并启用插件，然后输入 `/tft` 打开日历。首次使用及客户端 API 行为仍需在无限服实测。

## 整合方向

以下是候选方向，并非已经合并的功能：

- **冒险手记**：已有升级事件，可研究逐角色导入已有记录；跨角色历史与每日时长需要本工具箱自己的账号级数据。
- **TigerUI**：可评估装备升级提醒、任务 NPC、任务怪及服务 NPC 标记；战斗 HUD 留在 TigerUI。并行使用时要避免重复图标和提醒。
- **Questie / QuestieDB、任务中文补丁及随行地图**：优先探索兼容和联动，不复制任务数据库或插件代码。
- **宏工坊、声望工具**：属于后续可选辅助，先核实版本和功能范围；配置迁移工具及平台数据同步不属于当前核心。

整合前需逐项核实授权、依赖、接口稳定性及游戏客户端兼容性。本项目不包含第三方插件代码或数据库。
